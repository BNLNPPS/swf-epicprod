Trials

A trial is a small, real run of a composed configuration by the path production uses: the same tags, the same input, the same payload and submission, at a hundred events rather than the full sample, with outputs that expire. It counts toward no physics. Each is a standing task of its own and qualifies the path for the configuration named beside it: that it submits, its input is reachable, the software runs, the output is valid, and the destination accepts it — not that the physics is right, which needs statistics, and not that it will hold at scale.
